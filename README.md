# 🎓 EduGen AI

## AI-Powered Exam Preparation & Personalized Learning Platform

EduGen AI is an AI-powered educational application that helps students prepare for examinations using their own study material.

Users can upload a PDF, generate AI-powered questions, take mock tests, analyze their performance, identify weak topics and generate personalized study plans.

---

## 🚀 Features

### 📄 PDF Study Material
Upload college notes, textbooks or study material in PDF format.

### 🤖 AI Question Generation
Generate examination questions from uploaded study material using Llama 3.2.

### 🎯 Difficulty Selection
Generate questions according to:

- Easy
- Medium
- Hard

### 📝 Multiple Question Types
Supports:

- Multiple Choice Questions
- True/False
- Short Answer
- Long Answer

### 🧪 AI Mock Test
Students can take an AI-generated mock examination.

### 🔄 Answer Modification
Students can change their selected answers before submitting the test.

### 🏆 Automatic Scoring
The system automatically calculates the student's score and accuracy.

### 📊 Performance Dashboard
Displays:

- Score
- Accuracy
- Exam countdown
- Daily study hours
- Strong topics
- Weak topics

### 🧠 Topic-Level Analysis
The application analyzes performance topic-by-topic.

### ⚠️ Weak Topic Detection
Identifies topics where the student needs more practice.

### 🤖 AI Study Recommendations
Provides personalized recommendations based on test performance.

### 📅 Personalized Study Plan
Generates an AI-powered study schedule based on:

- Exam date
- Available study hours
- Test score
- Weak topics
- Strong topics
