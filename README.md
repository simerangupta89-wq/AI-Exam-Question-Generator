# 🎓 EduGen AI - AI Exam Question Generator

EduGen AI is an AI-powered application that helps students prepare for exams by generating questions from their study material.

## ✨ Features

- 📄 Upload PDF study material
- 🤖 Generate questions using AI
- 🔢 Choose number of questions
- 🎯 Choose Easy, Medium or Hard difficulty
- ✅ Get correct answers
- 💡 Get explanations
- 📊 View results
- 📅 Generate personalized study plans
- 📈 Identify weak topics
- 🧪 Practice with mock tests

## 🛠️ Technologies Used

- Python
- Streamlit
- Ollama
- Llama 3.2
- Natural Language Processing
- Prompt Engineering
- pypdf
- Git
- GitHub

## 🧠 How It Works

Student uploads PDF
↓
PDF text is extracted
↓
AI analyzes the study material
↓
Llama 3.2 generates questions
↓
Student practices questions
↓
Results and learning insights are displayed
